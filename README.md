# estilo-gestao-mvp
O **Estilo e Gestão** é um sistema SaaS completo para barbearias focado em transformar a gestão do seu negócio. Com ele, você controla o financeiro (faturamento e lucro real), gerencia o estoque e PDV de balcão com baixa automática, e aumenta a retenção de clientes com cartão de fidelidade digital e mensagens automatizadas via WhatsApp.
