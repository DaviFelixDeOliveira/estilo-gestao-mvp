# Design System — Estilo e Gestão

## Objetivo

Este documento define os padrões visuais e de interface do **Estilo e Gestão**.

Ele serve como referência para manter consistência entre todas as telas.

As regras de funcionamento pertencem ao documento de Fluxo Técnico.

As regras específicas de adaptação por tamanho de tela pertencem ao documento de Responsividade.

---

# 1. Princípios visuais

A interface deverá ser:

- simples;
- profissional;
- limpa;
- moderna;
- fácil de entender;
- adequada ao uso rápido;
- consistente;
- prioritariamente mobile.

Evitar excesso de:

- efeitos;
- gradientes;
- sombras;
- animações;
- informações simultâneas;
- elementos decorativos sem função.

---

# 2. Identidade visual

A identidade do Estilo e Gestão utiliza como base tons neutros relacionados à logo.

A aparência deverá transmitir:

- organização;
- confiança;
- simplicidade;
- modernidade.
